# Rogi 방송 데이터 API

후로기(`h66rogi`) 방송의 상태, 실시간 채팅, 지난 방송의 채팅 기록을 읽기 위한 공개 API 문서입니다.

기본 주소는 `https://data-api.rogi.chat`입니다. 첫 버전은 SOOP의 `h66rogi` 한 채널을 대상으로
하며 인증 없이 읽을 수 있습니다. 표준 WebSocket을 제공하고 Socket.IO는 지원하지 않습니다.

| 주제 | 내용 |
| --- | --- |
| [방송 상태](./status) | 방송 on/off와 수집 연결 상태를 구분합니다. |
| [실시간 채팅](./chat-stream) | WebSocket 이벤트와 재접속 규칙입니다. |
| [지난 방송](./history) | 방송·채팅 목록과 보관 품질 표시입니다. |
| [진행 상태](./roadmap) | 운영 범위와 알려진 제약입니다. |

모든 시각은 RFC 3339 형식의 UTC입니다. 요청 제한은 전체 API 기준 초당 20회, 순간 최대 60회이며
동시 WebSocket 연결은 32개까지입니다. 한도 초과 시 `429 rate_limited`와 `Retry-After: 1`을
반환합니다. 향후 API key 인증을 추가할 수 있습니다.
