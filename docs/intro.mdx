# Rogi 방송 데이터 API

후로기(`h66rogi`) 방송의 상태, 실시간 채팅, 지난 방송의 채팅 기록을 읽기 위한 공개 API 문서입니다.

:::caution 현재 상태

이 문서의 data-api 엔드포인트는 **설계 중**이며 아직 제공되지 않습니다. `data-api.rogi.chat`의
DNS, API 서버, 영구 채팅 archive는 아직 공개되지 않았습니다. 아래 계약은 구현과 실방송 검증 후 확정됩니다.

:::

| 주제 | 내용 |
| --- | --- |
| [방송 상태](./status) | 방송 on/off와 수집 연결 상태를 구분합니다. |
| [실시간 채팅](./chat-stream) | WebSocket 이벤트와 재접속 규칙입니다. |
| [지난 방송](./history) | 방송·채팅 목록과 보관 품질 표시입니다. |
| [진행 상태](./roadmap) | 공개 전 필요한 검증 단계입니다. |

첫 버전은 SOOP의 `h66rogi` 한 채널을 대상으로 합니다. 읽기는 익명으로 시작하고 향후 API key를
도입할 수 있습니다. 모든 시각은 RFC 3339 형식의 UTC로 전달할 계획입니다.
