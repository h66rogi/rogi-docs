# 방송 상태 (계획됨)

`GET https://data-api.rogi.chat/v1/broadcasts/current`

응답은 방송 자체의 상태와 collector의 채팅 수집 연결 상태를 **별도 필드**로 제공합니다.

```json
{
  "channelId": "h66rogi",
  "live": true,
  "state": "live",
  "checkedAt": "2026-09-23T08:00:00Z",
  "broadcastId": "example-broadcast-id",
  "collection": {
    "active": true,
    "state": "connected",
    "lastReceivedAt": "2026-09-23T08:00:05Z"
  }
}
```

예시는 형식 설명용 합성 데이터입니다. `state`는 `live`, `offline`, `cookie_required`,
`auth_required`, `lookup_failed` 중 하나입니다. 마지막 세 상태에서는 `live`가 `null`이며
이를 방송 종료로 해석하면 안 됩니다. `collection.active=false`는 방송이 꺼졌다는 뜻이 아닙니다.
