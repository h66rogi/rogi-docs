# 로기마블

로기마블은 방송 전체가 **하나의 말**을 공유하는 주루마블 게임입니다. 운영자는 웹 콘솔에서 보드와 규칙을 설정하고 세션·주사위·미션·아이템을 관리합니다. OBS에는 읽기 전용 오버레이를 표시합니다.

## 문서 길잡이

- [빠른 시작](./quickstart): 로그인, 세션 운영, OBS 화면 연결
- [게임 규칙과 상태](./game-rules): 후원 판정, 서버 결과, 보드 효과
- [rogi-collector 연동](/collector/): SOOP 입력을 게임에 전달하는 경계

## 현재 범위

수동 주사위, 세션 제어, 방향·위치 보정, 보상 수량과 미션 조작, 보드·규칙 초안 검증·게시, OBS 화면을 제공합니다. **후로기 실방송의 후원·채팅이 게임 결과까지 이어지는 전체 흐름은 아직 검증 완료로 표시하지 않습니다.** 일부 보드 효과는 게시 단계에서 거부될 수 있습니다.

웹 콘솔의 메뉴·동작은 [rogimarble 공개 저장소의 구현 기록](https://github.com/h66rogi/rogimarble/blob/main/docs/implementation-status.md)을 기준으로 정리했습니다. 운영 중 보이는 기능은 배포 버전에 따라 다를 수 있습니다.
