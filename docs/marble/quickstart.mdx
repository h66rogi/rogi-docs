# 운영 콘솔 빠른 시작

로기마블 콘솔은 [marble.rogi.chat](https://marble.rogi.chat)에서 엽니다. 접근 토큰으로 로그인한 뒤 권한이 있는 채널을 선택하세요. 토큰 원문은 계정 화면에서 발급·관리하며, 분실한 토큰은 다시 표시되지 않습니다.

## 1. 세션 준비

**설정 관리**에서 후원 규칙·아이템·보드·OBS 레이아웃의 초안을 저장하고 서버 검증을 실행합니다. 검증을 통과한 설정만 게시할 수 있습니다. 게시된 버전은 수정하지 않고 새 초안으로 갱신합니다. 지원하지 않는 보드 효과는 실게임 게시 단계에서 차단될 수 있습니다.

**게임 운영**에서 활성 세션을 확인하고 새 세션을 시작합니다. 세션 상태는 준비 → 실행 ↔ 일시정지 → 종료로 움직입니다. 종료 후 새 세션은 이전 세션의 말 위치·재고·미션을 자동 승계하지 않습니다.

## 2. 방송 중 조작

- **수동 주사위**: 서버가 주사위 눈과 이동 경로를 확정하고 결과를 저장합니다. 화면 연출은 저장된 결과를 재생합니다.
- **일시정지·한 건 진행·재개**: 자동 이동을 멈추거나 대기 중인 이동 한 건만 처리합니다.
- **방향·위치 보정**: 방향은 다음 미확정 이동부터 적용됩니다. 위치를 바로 바꾸면 이전 위치 연출은 취소됩니다.
- **보상·미션**: 수량 증감·지정, 수동 미션 생성·완료·면제, 실드 사용을 서버 기록으로 남깁니다.
- **후원 내역·운영 기록**: 저장된 후원의 처리 상태와 수동 조작 이력을 확인합니다. 수집 연결이 없으면 실제 후원 내역은 비어 있을 수 있습니다.

같은 명령을 재시도할 때는 콘솔이 보존한 명령 ID를 사용합니다. 응답이 늦었다는 이유로 새 명령을 연달아 실행하면 별개의 동작으로 기록될 수 있습니다.

## 3. OBS에 표시

**오버레이 설정 → 오버레이 주소**에서 통합 오버레이 주소를 복사해 OBS 브라우저 소스에 붙여 넣습니다. 통합 화면의 권장 크기는 **1920 × 1080**입니다. 필요하면 파츠별 주소를 따로 사용합니다. 주소에는 읽기 토큰이 포함되므로 방송 설명이나 공개 채팅에 공유하지 마세요. 주소를 교체하면 이전 주소가 중단되므로 OBS 소스도 갱신해야 합니다.

현재 구현 기록의 OBS 상태 전달은 주기적 조회 기반입니다. 화면의 애니메이션 완료 여부는 서버에 저장된 게임 결과를 바꾸지 않습니다.

## 수집 상태 확인

콘솔 상단의 **방송·수집 관리** 또는 `/collector`에서 수집기 연결과 마지막 입력 시각을 확인할 수 있습니다. 다른 SOOP 채널의 **방송 조회**는 현재 운영 수집 채널을 바꾸거나 게임 입력을 만들지 않습니다. 입력이 오래 없다는 것만으로 장애나 방송 종료로 판단하지 마세요.

자세한 운영 화면 계약은 [rogimarble의 방송·수집 관리 문서](https://github.com/h66rogi/rogimarble/blob/main/docs/collector-management.md)에 있습니다.
