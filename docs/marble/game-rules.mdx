# 게임 규칙과 상태

## 후원은 정확한 개수로 판정

후원 규칙은 등록한 **별풍선 개수와 정확히 일치**할 때만 선택됩니다. 33개 규칙이 있다고 해서 66개를 자동으로 두 번 실행하거나 여러 후원을 합산하지 않습니다. 연차는 별도 활성화와 개수별 `rollCount` 규칙이 모두 있어야 합니다. 규칙 이름·개수·동작은 콘솔에서 편집하는 데이터이며, 초기 프리셋이 영구적인 방송 규칙은 아닙니다.

수집기는 SOOP의 별풍선 종류와 정수 개수를 보존합니다. 게임에서 실행할 규칙, 미션과 말 이동은 로기마블 서버가 결정합니다. 후원 수집의 재접속 중복 의심 이벤트는 검토 대상으로 남길 수 있습니다.

## 서버가 결정하는 게임 결과

서버는 세션·설정 버전과 현재 말 위치를 기준으로 주사위 결과, 이동 경로, 칸 효과를 저장합니다. 콘솔과 OBS는 같은 결과를 표시합니다. 브라우저가 굴린 주사위나 애니메이션의 마지막 프레임이 게임 결과가 되지 않습니다.

보드의 칸은 표시 문구가 아니라 ID와 동작 타입으로 구분합니다. 기본 판은 9열 × 6행 외곽 **26칸**이며, 칸 수·내용·배치·효과를 분리해 편집할 수 있습니다. 수동 위치 변경과 후원으로 시작한 이동은 원장에 서로 다른 출처로 기록됩니다.

## 목적지 선택과 수집 공백

원하는 칸 이동은 운영자 선택 또는 후원자 채팅을 입력 방식으로 설정할 수 있습니다. 요청당 한 번만 목적지를 확정하고, 기다리는 동안 다음 이동은 대기합니다. 채팅 입력은 짧은 보존 범위와 연결 상태의 영향을 받으므로, 수신하지 못한 명령을 자동으로 재구성하지 않습니다.

수집 cursor가 만료되거나 저장 세대가 바뀌면 자동으로 최신 위치로 건너뛰지 않고 복구 필요 상태를 표시합니다. 실제 후로기 방송 입력부터 게임 결과·OBS까지의 통합 검증은 별도로 진행 중입니다.

설계와 구현 차이는 [rogimarble 구현 상태](https://github.com/h66rogi/rogimarble/blob/main/docs/implementation-status.md)에서 확인하세요.
