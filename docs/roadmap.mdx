# 진행 상태

| 단계 | 상태 |
| --- | --- |
| collector 내부 실시간 채팅 수집·private gRPC | 운영 중. 후로기 본인 실방송 최종 검증은 별도 |
| 영구 채팅 archive와 방송별 색인 | 계획됨 |
| 공개 Go data-api와 Cloudflare Tunnel | 계획됨 |
| `docs.rogi.chat` 정적 문서 사이트 | 구축 중 |

[설계 원문](https://github.com/h66rogi/rogi-collector/blob/main/docs/public-data-api-design.md)을 기준으로
구현 단계마다 명세를 갱신합니다. 페이지에 `계획됨`으로 표시된 기능은 공개 API가 아닙니다.
