# 지난 방송과 채팅

지난 방송은 `sessionId`로 구분합니다. 이 ID는 [현재 방송 상태](./status)의 플랫폼 `broadcastId`와 다릅니다. 인증 없이 조회할 수 있습니다.

## 방송 목록

`GET /v1/broadcasts?cursor=&limit=`은 방송 시작 시각의 최신순으로 반환합니다.

```sh
curl -fsS 'https://data-api.rogi.chat/v1/broadcasts?limit=20'
```

```json
{
  "broadcasts": [
    {
      "sessionId": "606c9e5a-05ab-4b25-a5c2-ef03870a73a4",
      "startedAt": "2026-09-23T08:00:00Z",
      "endedAt": "2026-09-23T10:00:00Z",
      "title": "방송 제목",
      "recordingStartedAt": "2026-09-23T08:02:05Z",
      "sourceGapDetected": false,
      "knownArchiveGap": false,
      "complete": false
    }
  ],
  "nextCursor": null
}
```

`limit` 기본값은 20, 최대값은 100입니다. 채팅이 한 건 이상 보관된 방송만 목록에 나타납니다. 방송 중이면 `endedAt`은 `null`일 수 있습니다. 제목이 없으면 `title`은 `null`입니다.

## 방송 채팅

`GET /v1/broadcasts/{sessionId}/chats?cursor=&limit=`은 보관된 채팅을 `position` 오름차순으로 반환합니다.

```sh
curl -fsS 'https://data-api.rogi.chat/v1/broadcasts/606c9e5a-05ab-4b25-a5c2-ef03870a73a4/chats?limit=50'
```

```json
{
  "sessionId": "606c9e5a-05ab-4b25-a5c2-ef03870a73a4",
  "chats": [
    {
      "eventId": "example-event-id",
      "sessionId": "606c9e5a-05ab-4b25-a5c2-ef03870a73a4",
      "position": 12345,
      "receivedAt": "2026-09-23T08:02:05Z",
      "user": {
        "id": "pseudonymous-user-id",
        "idVersion": 1,
        "displayName": "시청자"
      },
      "message": "안녕하세요"
    }
  ],
  "nextCursor": null,
  "complete": false
}
```

`limit` 기본값은 50, 최대값은 200입니다. `position`은 전체 보관 채팅에 부여하는 **수집·저장 순번**입니다. 방송마다 1부터 시작하거나 연속으로 증가하지 않으며 SOOP의 전역 채팅 순서도 아닙니다. `user.id`는 원본 사용자 ID가 아닌 가명이며, `idVersion`이 바뀌면 같은 사용자의 값도 달라질 수 있습니다.

## 페이지 넘기기

`nextCursor`가 문자열이면 같은 경로에 `cursor`로 전달하세요. `null`이면 현재 페이지 뒤에 반환할 항목이 없습니다. cursor는 수정하거나 다른 목록·방송에 재사용하지 마세요.

```sh
curl -fsSG 'https://data-api.rogi.chat/v1/broadcasts' --data-urlencode 'cursor=YOUR_NEXT_CURSOR'
```

잘못된 `cursor`나 범위를 벗어난 `limit`는 `400`, 존재하지 않는 `sessionId`는 `404`, 보관 저장소를 읽을 수 없으면 `503`입니다. [오류 목록](./errors)

## 보관 범위와 품질

채팅 기록에 시간 기준 자동 삭제 정책은 없습니다. 보관 기능이 켜지기 전의 채팅, 수집되지 않은 채팅, 채팅이 없는 방송은 조회할 수 없습니다. 최근 채팅의 Redis 보존 범위와 지난 방송의 보관 범위는 별개입니다.

| 필드 | 해석 |
| --- | --- |
| `recordingStartedAt` | 해당 방송에서 처음 보관된 채팅을 받은 시각. 방송 시작보다 늦을 수 있습니다. |
| `sourceGapDetected` | 방송 탐색기가 재시작 후 탐색 관측 공백을 감지했는지 여부. 채팅 연결·저장 공백을 직접 측정하지 않습니다. |
| `knownArchiveGap` | 보관 스풀 저장 실패가 감지된 방송이면 `true`입니다. `false`도 누락이 없다는 뜻은 아닙니다. |
| `complete` | `false`를 반환합니다. 전체 방송 채팅의 무누락 수집이 확인되지 않았음을 뜻합니다. |

예시는 모두 형식 설명용 데이터입니다.
